# 嘻哈風格發展 LLM Wiki

以繁體中文整理美國嘻哈風格在 1990 年代至 2020 年代的形成、並行發展與融合，必要時回溯背景。主線包括 Boom bap、南方嘻哈、Trap、網路世代與 Rage，面向不熟悉嘻哈、但對音樂有興趣的讀者。

地域、曲風、平台與場景是不同的分析面向；上述主線是研究範圍，不代表已確認的分類或依序替代關係。維護與證據規則見 [AGENTS.md](AGENTS.md)。

## 閱讀與證據方式

實質條目前半提供容易閱讀的歷史整理，後半保留主張表、分歧、待查問題與檢查狀態。前半的重要主張也需就近引用來源筆記中的證據段落。

來源使用穩定的 S001、S002 等 ID；頁內重要主張使用 C01、C02 等編號，跨頁引用以「頁面路徑＋主張編號」識別。事實、當事人自述、作者觀點、綜合解讀與待查／有分歧須明確區分。同篇轉載、格式版本或引用同一訪談的報導，不自動增加獨立來源數。

ingest 狀態分為 pending、blocked、partial、complete；檢查狀態另行記錄。只有取得足夠主要內容、建立來源筆記、更新至少一個實質條目、索引及操作紀錄並留下檢查結果，才列 complete。詳細條件沿用 [AGENTS.md](AGENTS.md)。
